# De Plaat Website

Statische erste Version der Website fuer das Vinyl Cafe De Plaat in Esens.

## Lokal ansehen

```bash
python3 -m http.server 8080
```

Dann im Browser `http://localhost:8080` oeffnen.

## Container

Der Container baut einen kleinen Go-Webserver und liefert die statischen Dateien auf Port 8080 aus.
